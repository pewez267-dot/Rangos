FantasticKits GUI Textures
==========================

This directory contains GUI texture files for the mod.
The mod uses programmatic rendering (fills, borders) matching the FantasticCrates/FantasticSpawners
dark theme style. Custom PNG textures can be placed here to override the programmatic background.

Expected texture files:
- kit_edit.png   : 256x256 background for the Kit Editor screen
- kit_claim.png  : 256x256 background for the Kit Claim screen

Texture specifications (FantasticCrates-style):
- Base color: #1A1A2E (dark navy)
- Border color: #6A4AC4 (purple accent) or #4A4A6A (subtle gray)
- Header bar: #16213E (slightly lighter navy)
- Slot background: #2A2A4A outer, #0F0F1F inner
- Text colors: Gold (#FFD700) for titles, White (#FFFFFF) for values, Gray (#AAAAAA) for labels
